# IPL Data Analysis & Strategic Insights for RCB

Performance analysis, player evaluation, and team strategy recommendations for Royal Challengers Bangalore (RCB) using SQL.

## Objective
To analyse IPL data and find performance trends, key player impact, and auction strategy ideas for RCB.

## Tools Used
- MySQL Workbench
- Google Sheets
- Microsoft Word and PowerPoint (for reporting and presentation)

## Dataset
IPL ball-by-ball and match data with around 70,000 rows across multiple tables (matches, ball-by-ball, players, teams, seasons).

## What I Did
- Answered 15 business questions using SQL queries
- Used joins, subqueries, aggregations and CASE statements to get insights
- Checked every query result before writing the answer
- Built a presentation with the key findings and recommendations

## Key Findings
- RCB won 9 matches in 2013, one of its strongest seasons
- RCB's win rate was about 55% when CH Gayle played, compared to about 38% when he did not
- RCB's death-overs bowling economy was 9.29, which shows a clear area to improve
